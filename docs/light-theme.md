# Light theme

White background with a deep teal accent retains the SEED component shapes and spacing.

| Role | Color | Contrast on white |
|---|---|---|
| Main text | #202927 | 14.92:1 |
| Secondary text | #65716c | 5.08:1 |
| Accent | #23705f | 5.91:1 |
| Hover | #f1f4f2 | — |
| Current menu | #edf4f1 | 5.29:1 with accent text |

Navigation retains its size during hover and selection; no inset underline, scaling or shadow. Keyboard focus uses a 2px teal outline. Motion is limited to 140ms color transitions and respects reduced motion. Chart backgrounds, axes and categorical colors use the same light theme. The concept map retains its own space visualization.
