# NAMONEYBERG 게시 브리핑

이 브랜치는 공개 게시본 전용 저장소입니다. 앱 코드는 [main](https://github.com/knh251510-afk/namoneyberg/tree/main)에 있습니다.

- `published_briefings/overview_*.json`: 관리자가 게시한 브리핑. 앱이 조회하는 경로이므로 유지합니다.
- 앱의 `BRIEFING_GITHUB_BRANCH` 기본값은 `briefing-data`입니다.
- API 키, 편집 전 초안·비공개 이력, 캐시, 앱 코드·이미지·폰트를 이 브랜치에 추가하지 않습니다.
- 게시하려면 저장소 Contents 쓰기 권한이 필요합니다. API 키나 토큰 자체는 파일에 넣지 않습니다.

2026-10-22 정리에서 기존 앱 복사본과 생성 파일을 제거했습니다. 게시본 경로와 내용은 유지했으며 Git 이력은 재작성하지 않았습니다.
