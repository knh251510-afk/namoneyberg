# Global Macro Atlas / LOE Weekly

로컬 주소: http://127.0.0.1:8501
VS Code에서 `.venv` 인터프리터를 선택하고 `run_dashboard.py`를 ▶ 실행합니다.

## 화면
- 세계 요약: 30개 경제권 선택, 연간 CPI·GDP·실업률 및 일간 정책금리.
- 물가·정책금리: BIS 월간 CPI 전년동월비와 정책금리, 일부 국가 PPI.
- 경기·무역 비교: 세계은행 연간 12개 지표, 국가·기간 선택 및 동일연도 비교.
- 시장·고빈도: 미국 CPI·근원 CPI·PCE·고용·산업생산·소매판매·주택, 국채·유가·환율·VIX.
- 이번 주 마켓 오버뷰 / LOE 위클리: 국내외 RSS, 매크로·글로벌·산업별 최대 3개 요약, 원문 근거, 보고서 다운로드.
- LOE 추적: Eurostat 유로존 PPI 전월비, 미국 신규 실업수당, 일본 내각부 소비자신뢰, 한국 경상수지(ECOS 키 필요).

## 인증과 비용
일반 통계는 별도 키 없이 조회합니다. 한국 월간 경상수지는 별도 ECOS 인증키가 필요합니다.
AI 요약은 OpenAI 연결란에 키를 입력하고 생성 버튼을 누릅니다. API 비용이 발생합니다.
Mac 키체인 저장을 선택할 수 있으며 키를 결과 파일이나 캐시에 저장하지 않습니다.
유료 API 호출은 버튼을 눌렀을 때만 수행합니다. API 호출·결제는 자동 30분 갱신 대상에서 제외합니다.

## 데이터 갱신
화면이 열려 있는 동안 30분마다 다시 실행합니다. 통계 캐시는 6시간, FRED는 1시간, 뉴스는 30분입니다.
데이터 새로고침 버튼은 다음 조회를 강제합니다. 연결 실패 시 기존 데이터와 조회 시각을 표시합니다.
컴퓨터가 꺼져 있으면 수집하지 않습니다. 통계 관측일, 실제 발표일, 조회일은 서로 다릅니다.

## 범위와 한계
모든 국가의 모든 월간 지표가 연결된 것은 아닙니다. PMI 등 유료·제한 데이터는 포함하지 않습니다.
시장 예상치가 연결되지 않아 컨센서스 열은 비워둡니다. 이전값은 수정된 현재 DB값입니다.
뉴스 요약은 제목과 RSS 제공 설명 기반이며 유료 원문 전체를 읽지 않습니다.
AI 출처 식별자와 분류별 수 제한을 검증하지만 사실 검증을 완전히 자동화하지는 않습니다.
PPI 산업 범위, CPI 계절조정, 유로존 중복 및 정책금리 정의 차이를 확인해야 합니다.
주간 시장 변화는 이전 주 마지막 관측 대비 이번 주 최신 관측으로 계산합니다. 선물·지수·현물 구분과 시각을 표시합니다.

## 검증
공식 공급원 실제 연결 확인 및 Streamlit 페이지 실행 검증.
주간 경계·미래 뉴스 제외·누락월 처리·잘못된 AI 출처 거부는 `test_macro.py`로 검증합니다.
실제 OpenAI 생성은 사용자가 키를 입력한 뒤 확인해야 합니다.
